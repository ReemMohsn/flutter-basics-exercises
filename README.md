# Flutter Basics Exercises

A collection of foundational **Flutter & Dart** practice projects built while learning mobile UI layouts, widgets, and basic state management (`setState`).

## 📂 Included Projects

| Project | Description | Key Concepts |
| :--- | :--- | :--- |
| [Picture Matching Game](./picture-matching-game) | Interactive image-matching game that compares randomly generated images on tap. | `StatefulWidget`, `setState`, Randomization, Assets |
| [Personal Information Card](./personal-info-card) | Clean profile card UI displaying personal and contact information. | `StatelessWidget`, `CircleAvatar`, `Card`, `ListTile`, Custom Fonts |
| [General Questions Quiz](./general-questions-quiz) | True/False general knowledge quiz app with instant feedback and score tracking. | `StatefulWidget`, Lists & Models, Conditional Logic, Dialogs |

## 🛠️ Tech Stack

- **Framework:** Flutter
- **Language:** Dart
- **UI:** Material Design Widgets

```bash
cd <project-folder-name>
